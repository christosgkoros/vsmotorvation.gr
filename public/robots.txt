# Όλα τα crawlers είναι ευπρόσδεκτα, συμπεριλαμβανομένων εκείνων που
# τροφοδοτούν ChatGPT, Gemini, Claude, Copilot και Perplexity. Οι ομάδες
# είναι γραμμένες ρητά επειδή ένα robots.txt εφαρμόζει στο κάθε bot ΜΟΝΟ
# την πιο συγκεκριμένη ομάδα που ταιριάζει — ένα σκέτο `User-agent: *`
# δουλεύει σήμερα, αλλά χάνεται μόλις προστεθεί οποιοσδήποτε περιορισμός.

User-agent: *
Allow: /

# ── OpenAI ──────────────────────────────────────────────
# GPTBot: εκπαίδευση.  OAI-SearchBot: ευρετήριο του ChatGPT Search.
# ChatGPT-User: όταν ο χρήστης ζητά ρητά να ανοίξει τη σελίδα.
User-agent: GPTBot
Allow: /

User-agent: OAI-SearchBot
Allow: /

User-agent: ChatGPT-User
Allow: /
